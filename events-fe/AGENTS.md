Frontend rules for this repository:

- Use React + TypeScript
- Use MUI for all UI
- Do not use inline styles
- Create separated files for css
- Organize code by feature
- Separate API, types, pages, and components
- Prefer reusable components where justified
- Use axios for API calls
- Use react-router-dom for routing
- Keep code simple and readable
- Do not modify backend files
- Before larger changes, explain the plan first
- Avoid unnecessary dependencies
- Match the existing project structure and naming conventions
